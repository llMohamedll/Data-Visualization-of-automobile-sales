# Project title: Data Visualization of automobile sales

## Overview
Comprehensive visualization toolkit demonstrating line plots, bar charts, pie charts, box plots, scatter plots, heatmaps, and interactive Folium maps.

## Original Notebook
- `DV0101EN-Final-Assign-Part1-v1.jupyterlite.ipynb`

## Key Skills Demonstrated
- Matplotlib: line, bar, scatter, box, pie charts
- Seaborn: heatmaps, statistical visualizations
- Folium: interactive choropleth and marker maps
- Multi-panel figure layouts
- Annotation and styling best practices

## How to Run
```bash
pip install pandas numpy matplotlib seaborn folium requests
python main.py
```

## Outputs
- `automobile_sales_trend.png` - Sales trends with recession markers
- `vehicle_type_analysis.png` - 4-panel vehicle type breakdown
- `advertising_analysis.png` - Advertising vs sales correlation
- `automobile_sales_map.html` - Interactive Folium map

## Key Findings
- Recessions significantly impact automobile sales
- SUV and Truck segments more resilient during downturns
- Advertising expenditure shows positive correlation with sales
- Interactive maps enhance geographic data exploration
